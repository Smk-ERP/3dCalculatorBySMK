ຕັ້ງຄ່າເຄື່ອງພິມ

ເຮັດເທື່ອດຽວຕໍ່ເຄື່ອງ · ຫຼັງຈາກນັ້ນບໍ່ຕ້ອງເຮັດອີກ
  • ເລືອກເຄື່ອງພິມຈາກລາຍການ ແລ້ວກົດ ✏️ ເພື່ອແກ້ໄຂ
  • ຫຼືກົດ + ເພີ່ມເຄື່ອງພິມ ຖ້າມີເຄື່ອງໃໝ່
ກຳລັງໄຟ (W)ເບິ່ງຈາກປ້າຍຫຼັງເຄື່ອງ

ຄ່າໄຟ / kWhເບິ່ງຈາກໃບເກັບເງິນ

ໃສ່ຂໍ້ມູນງານ

ເຮັດທຸກຄັ້ງ ສຳລັບແຕ່ລະຊິ້ນສ່ວນ
  • ຊື່ຊິ້ນສ່ວນ — ເຊັ່ນ ຫົວ, ລຳຕົວ, ແຂນຊ້າຍ (ຈຳເປັນ ຕ້ອງໃສ່)
  • ນ້ຳໜັກ ແລະ ຊົ່ວໂມງພິມ — copy ມາຈາກໂປຣແກຣມ slicer
  • ຄ່າເພີ່ມເຕີມ — ໃສ່ສະເພາະທີ່ມີ ບ່ອນໃດບໍ່ມີປະໄວ້ 0

3

ບັນທຶກຊິ້ນສ່ວນ

ລາຄາຄິດໄລ່ອັດຕະໂນມັດທັນທີ
  • ເບິ່ງ ລາຍລະອຽດຄ່າໃຊ້ຈ່າຍ ແລະ ລາຄາຂາຍ ວ່າສົມເຫດສົມຜົນບໍ
  • ກົດ 💾 ບັນທຶກຊິ້ນສ່ວນ
  • ຖ້າງານມີຫຼາຍຊິ້ນ — ກັບໄປຂັ້ນຕອນທີ 2 ເຮັດຊ້ຳຈົນຄົບ
💡 ປ່ຽນເຄື່ອງພິມໄດ້ລະຫວ່າງແຕ່ລະຊິ້ນ — ແຕ່ລະຊິ້ນຈື່ວ່າພິມດ້ວຍເຄື່ອງໃດ.
4

ກວດສະຫຼຸບໂຄງການ

ລວມທຸກຊິ້ນເຂົ້າກັນໃຫ້ອັດຕະໂນມັດ
  • ເບິ່ງ ນ້ຳໜັກລວມ · ຊົ່ວໂມງລວມ · ຄ່າໃຊ້ຈ່າຍລວມ · ລາຄາຂາຍລວມ
  • ຊິ້ນໃດຜິດ ກົດ ✕ ລຶບສະເພາະຊິ້ນນັ້ນ ແລ້ວໃສ່ໃໝ່
5

ພິມໃບສະເໜີລາຄາ

ສົ່ງໃຫ້ລູກຄ້າ ຫຼື ເກັບໄວ້ເປັນຫຼັກຖານ
  • ກົດ 🖨 ພິມໃບສະເໜີ — ຈະເປີດໜ້າຕ່າງໃໝ່
  • ກົດ 🖨️ Print / Save PDF
  • ເລືອກ Save as PDF ເພື່ອເກັບເປັນໄຟລ໌ ຫຼືເລືອກເຄື່ອງພິມເພື່ອພິມອອກ
  • ຈົບງານແລ້ວ ກົດ ລຶບທັງໝົດ ເພື່ອເລີ່ມງານໃໝ່
📌 ບັນທຶກ PDF ໄວ້ທຸກເທື່ອ — ນີ້ຄືວິທີດຽວທີ່ຈະເກັບຂໍ້ມູນງານໄວ້ຖາວອນ.
🧮 ສູດຄິດໄລ່ — ລາຄາມາຈາກໃສ
ຄິດໄລ່ອັດຕະໂນມັດຈາກຂໍ້ມູນເຄື່ອງພິມ + ນ້ຳໜັກ + ຊົ່ວໂມງ
ຄ່າທີ່ເຈົ້າໃສ່ເອງແຕ່ລະງານ
ບວກເຜື່ອງານເສຍ ຕາມ % ທີ່ຕັ້ງໄວ້
ຕົວເລກສຸດທ້າຍທີ່ສະເໜີລູກຄ້າ
💾 ຂໍ້ມູນເກັບຢູ່ໃສ — ສິ່ງທີ່ຕ້ອງລະວັງ

✅ ເຮັດແບບນີ້

  • ພິມໃບສະເໜີເປັນ PDF ເກັບໄວ້ທຸກງານ
  • ໃສ່ຕົວເລກຈິງຂອງເຄື່ອງກ່ອນເລີ່ມໃຊ້
  • ກວດລາຄາຂາຍວ່າສົມເຫດສົມຜົນກ່ອນສົ່ງລູກຄ້າ

⚠️ ຂໍ້ຄວນລະວັງ

  • ຂໍ້ມູນເກັບໃນ browser ຂອງແຕ່ລະເຄື່ອງ ແຍກກັນ — ຕັ້ງໃນຄອມ ຈະບໍ່ໄປປາກົດຢູ່ໂທລະສັບ
  • ລ້າງ browser data = ເຄື່ອງພິມ ແລະ ຊິ້ນສ່ວນທີ່ບັນທຶກຈະຫາຍໝົດ
  • ບໍ່ມີການ sync ຂ້າມເຄື່ອງ ແລະ ບໍ່ມີການ backup ອັດຕະໂນມັດ
