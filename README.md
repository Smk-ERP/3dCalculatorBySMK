## ວິທີໃຊ້ / How to use

**ກົດ 2 ເທື່ອທີ່ `index.html`** — ຫັ້ນແລ້ວ. ບໍ່ຕ້ອງເຮັດຫຍັງອີກ.

ຫຼືກົດ `Launch Calculator.bat`.

ໄຟລ໌ `index.html` ລວມ React, htm ແລະ CSS ທັງໝົດຢູ່ໃນຕົວມັນເອງແລ້ວ (191 KB).
ບໍ່ມີການດຶງຂໍ້ມູນຈາກອິນເຕີເນັດເລີຍ — ສະນັ້ນມັນຈະໃຊ້ໄດ້ຕະຫຼອດ.

---

## ໃຊ້ຢູ່ໂທລະສັບ / Use on your phone

1. Copy `index.html` ໃສ່ໂທລະສັບ (USB, Google Drive, LINE, ອີເມວ — ອັນໃດກໍໄດ້)
2. ເປີດດ້ວຍ Chrome / Safari
3. ກົດ **Share → Add to Home Screen** — ຈະໄດ້ icon ຄືແອັບຈິງ

ຂໍ້ມູນທີ່ບັນທຶກຈະຢູ່ໃນເຄື່ອງນັ້ນເອງ (localStorage) — ບໍ່ sync ຂ້າມເຄື່ອງ.

## ໄຟລ໌ໃນໂຟເດີ້ນີ້ / Files

| ໄຟລ໌ | ໜ້າທີ່ |
|---|---|
| `index.html` | **ແອັບຕົວຈິງ** — ໄຟລ໌ດຽວ ໃຊ້ໄດ້ເລີຍ |
| `Launch Calculator.bat` | ປຸ່ມເປີດແອັບ |
| `Rebuild.bat` | ສ້າງ `index.html` ຄືນໃໝ່ຫຼັງແກ້ code |
| `build.ps1` | script ລວມໄຟລ໌ |
| `src/app.js` | code ຂອງແອັບ (ແກ້ບ່ອນນີ້) |
| `src/styles.css` | ສີ ແລະ ຮູບແບບ (ແກ້ບ່ອນນີ້) |
| `lib/` | React 18 + htm (ດາວໂຫຼດມາເກັບໄວ້ແລ້ວ) |

### ຖ້າຢາກແກ້ແອັບ

1. ແກ້ `src/app.js` ຫຼື `src/styles.css`
2. ກົດ `Rebuild.bat`
3. Refresh ໜ້າເວັບ

> ⚠️ ຢ່າແກ້ `index.html` ໂດຍກົງ — ມັນຈະຖືກຂຽນທັບຕອນ rebuild.

## ສູດຄິດໄລ່ / Formula

```
ຄ່າວັດສະດຸ      = (ນ້ຳໜັກ ÷ 1000) × ລາຄາເສັ້ນໄຫມ/ກກ
ຄ່າໄຟຟ້າ        = (ວັດ ÷ 1000) × ຊົ່ວໂມງ × ຄ່າໄຟ/kWh
ຄ່າແຮງງານ      = (ຄ່າແຮງຕໍ່ວັນ ÷ 8) × ຊົ່ວໂມງ
ຄ່າເສື່ອມລາຄາ   = ຄ່າເສື່ອມ/ຊມ × ຊົ່ວໂມງ

ຄ່າພື້ນຖານ = ຄ່າວັດສະດຸ + ຄ່າໄຟຟ້າ + ຄ່າແຮງງານ + ຄ່າເສື່ອມ
           + ຄ່າເກັບລາຍລະອຽດ + ຄ່າເຮັດສີ + ຄ່າຂື້ນແບບ + ຄ່າສົ່ງ

ຄ່າສິ່ງເສດ = ຄ່າພື້ນຖານ × % ສິ່ງເສດ
ຄ່າລວມ    = ຄ່າພື້ນຖານ + ຄ່າສິ່ງເສດ
ລາຄາຂາຍ   = ປັດຂຶ້ນເປັນ 10 ບາດ( ຄ່າລວມ × (1 + % ກຳໄລ) )
```

ລາຄາທັງໝົດເປັນ **ເງິນບາດໄທ (THB)**.

## ຄ່າເລີ່ມຕົ້ນເປັນຄ່າສົມມຸດ / Default values are placeholders

ຕົວເລກລາຄາທັງໝົດໃນ code (ຄ່າເສັ້ນໄຫມ, ຄ່າແຮງ, % ກຳໄລ ແລະ ອື່ນໆ) ເປັນ
**ຄ່າກາງໆ ບໍ່ແມ່ນຕົວເລກຈິງ**. ໃສ່ຕົວເລກຂອງເຈົ້າເອງດ້ວຍປຸ່ມ ✏️ —
ຂໍ້ມູນຈະເກັບຢູ່ໃນ browser ຂອງເຈົ້າເທົ່ານັ້ນ ບໍ່ຂຶ້ນ GitHub.

ສະເພາະ ກຳລັງໄຟ (W) ແລະ ຂະໜາດພິມ ເປັນສະເປັກຈິງຂອງເຄື່ອງ ເຊິ່ງເປັນຂໍ້ມູນສາທາລະນະຢູ່ແລ້ວ.
